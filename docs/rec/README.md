# rec/ — video explicativo

Este directorio contiene el video asciinema de **InHand Router** y el reproductor
que se usa en la página del proyecto.

- `inhand-router.cast`: grabación original (asciicast v2).
- `inhand-router.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:34. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
