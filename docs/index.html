01 — El proyecto

Qué resuelve

Documento de campo sobre un router industrial InHand: se cambió la LAN de 192.168.1.1 a 192.168.2.1, se ajustó el pool DHCP y se intentó habilitar SSH. Al no estar disponible dropbear, la intervención se revirtió y el equipo quedó como estaba.

Problema

El punto de partida

Tocar un router industrial sin registrar el estado original convierte una configuración en una caja negra imposible de recuperar.

Solución

La propuesta

Documentar modelo, serial, firmware, cada comando y la reversión. Si una capacidad no existe, se declara y se vuelve atrás.

El concepto

Qué es y por qué existe

Informe de intervención sobre un router industrial InHand IG601PS08, de la serie InGateway 600. Documenta el cambio de LAN de 192.168.1.1 a 192.168.2.1, el ajuste del pool DHCP, un intento fallido de habilitar SSH y la reversión completa al estado original, con modelo, serial y firmware identificados.

No es un tutorial ni un firmware: es el registro de una operación de campo. Sirve a quien deba tocar un equipo del que no hay documentación propia y necesite dejar rastro de cada comando. Importa porque el activo no es el cambio, sino la capacidad de volver atrás y de declarar con precisión lo que no se pudo hacer.

Lo que no funcionó

Los tropiezos, documentados

Las primeras versiones existen para que estos errores no se repitan: cada una dejó una decisión de diseño verificable.

inhand-router

SSH imposible sin dropbear

Se activó sshd_enable=1 por la interfaz web y el valor quedó en nvram, pero el puerto 22 nunca abrió. El log mostraba «failed to execute dropbear! ret: -1, err: 2», porque el firmware no incluye el binario. Se revirtió a 0 para no dejar un servicio fallando en bucle.

inhand-router

Enlace WAN sin validar

El equipo reportaba un reloj desajustado, alrededor de 2031, y ninguna ruta por defecto, con el módem Siemens PHS8 registrado pero sin sesión PPP activa. No se intentó corregir el dial porque el alcance era el cambio de LAN; la limitación quedó escrita en el informe.

Preguntas típicas

Lo que suelen preguntar

¿Hay código?

No. Es un informe de cambios y reversión.

¿Por qué no se habilitó SSH?

El firmware no incluía dropbear y se decidió no instalar paquetes no soportados.

¿Se puede replicar?

Sí, con el mismo modelo y firmware, pero verificá siempre el estado inicial.

¿Se publican las contraseñas?

No. Se omitieron deliberadamente.

¿El router quedó modificado?

No. La LAN se revirtió y el equipo quedó como estaba.
